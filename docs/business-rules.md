# 비즈니스 규칙

## 사용자 (User)

### 회원가입

| 항목 | 규칙 |
|------|------|
| 이메일 | 유효한 이메일 형식, 중복 불가 |
| 비밀번호 | 8자 이상, BCrypt 해시 저장 |
| 닉네임 | 2-20자, 중복 불가 |
| 이름 | 2-20자 |

### 회원 탈퇴

| 항목 | 규칙 |
|------|------|
| 처리 방식 | Soft Delete (deleted_at 설정) |
| 작성 게시글 | 유지 (작성자 표시: "탈퇴한 사용자") |
| 댓글 | 유지 |
| 좋아요/북마크 | 삭제 |

---

## 게시글 (Post)

### 작성 규칙

| 항목 | 규칙 |
|------|------|
| 제목 | 1-100자 |
| 내용 | 1-10000자 |
| 이미지 | 선택, 장소 없는 사진 최대 10장 + 장소당 최대 3장 |
| 도시 | 필수 선택 |
| 카테고리 | 필수 선택 |

### 상태 관리

| 상태 | 설명 |
|------|------|
| DRAFT | 임시저장 (본인만 조회 가능) |
| PUBLISHED | 게시됨 (전체 공개) |
| HIDDEN | 숨김 (관리자 처리) |

### 정렬/필터

| 옵션 | 설명 |
|------|------|
| newest (기본) | 최신순 |
| popular | 좋아요순 |
| views | 조회수순 |
| 지역 필터 | region_id, city_id |
| 카테고리 필터 | category_id, sub_category_id |

---

## 좋아요 (Like)

| 항목 | 규칙 |
|------|------|
| 중복 | 불가 (user_id + post_id unique) |
| 토글 | 좋아요/취소 한 엔드포인트로 처리 |
| 카운트 | post.like_count 역정규화 (동기화) |

---

## 이미지 (Image)

| 항목 | 규칙 |
|------|------|
| 허용 확장자 | jpg, jpeg, png, webp |
| 최대 크기 | 10MB |
| 최대 개수 | 장소 없이 올리는 사진은 게시글당 10장, 장소 사진은 장소당 3장 |
| 저장소 | AWS S3 |

---

## 댓글 (Comment) - v3

| 항목 | 규칙 |
|------|------|
| 글자 수 | 1-500자 |
| 수정 | 작성자 본인만 |
| 삭제 | 작성자 본인만 (soft delete) |
| 대댓글 | v4에서 parent_id 추가로 지원 |

---

## 북마크 (Bookmark) - v3

| 항목 | 규칙 |
|------|------|
| 중복 | 불가 (user_id + post_id unique) |
| 토글 | 추가/삭제 한 엔드포인트로 처리 |

---

## 신고 (Report) - v3

### 신고 사유

```
- 허위 정보
- 부적절한 내용
- 스팸/광고
- 저작권 침해
- 기타
```

### 처리 프로세스

```
1. 사용자 신고
2. 관리자 검토
3. 승인 → 게시글 숨김 (HIDDEN)
4. 반려 → 유지
```

---

## 지역/카테고리

### 지역 구조

```
Region (시/도)
  └── City (구/군)
```

### 카테고리 구조

```
Category (메인: 여행가자, 맛집가자, 놀러가자)
  └── SubCategory (상세)
```

### 캐싱

- 지역, 카테고리 데이터는 Caffeine Cache 적용
- 변경이 거의 없는 마스터 데이터
